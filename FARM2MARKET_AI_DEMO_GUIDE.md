# 🌾 Farm2Market AI - Complete Demo Guide

## 🎯 System Overview

Farm2Market AI is a comprehensive LINE bot solution designed for **all types of farms** to connect directly with market stores through AI-powered market matching. The system helps farmers sell their products efficiently by providing intelligent demand analysis, automated buyer matching, and professional marketing tools.

### 🚀 Supported Farm Types
- **🥚 雞蛋類** (Eggs) - Chicken eggs, duck eggs, quail eggs
- **🥬 蔬菜類** (Vegetables) - Leafy greens, root vegetables, herbs
- **🍎 水果類** (Fruits) - Seasonal fruits, berries, citrus
- **🌾 穀物類** (Grains) - Rice, wheat, corn, oats
- **🥛 乳製品** (Dairy) - Milk, cheese, yogurt, butter
- **📝 自訂規格** (Custom) - Any other farm products

## 🔧 Technical Setup Guide

### Prerequisites
1. **LINE Developer Account**: Required for bot creation
2. **Firebase Project**: For backend services
3. **Google Gemini API**: For AI functionality
4. **Domain/Hosting**: For web dashboard

### Step-by-Step Setup

#### 1. LINE Bot Configuration
```bash
# 1. Create LINE Official Account
# 2. Get Channel Access Token
# 3. Set Webhook URL: https://your-domain.com/webhook
# 4. Enable Webhook
```

#### 2. Firebase Setup
```bash
# 1. Create Firebase project
firebase init

# 2. Enable Firestore Database
# 3. Configure Functions
# 4. Set environment variables
firebase functions:config:set \
  line.channel_access_token="YOUR_LINE_TOKEN" \
  line.channel_secret="YOUR_LINE_SECRET" \
  gemini.api_key="YOUR_GEMINI_KEY"
```

#### 3. Deploy Functions
```bash
# 1. Build functions
cd functions && npm run build

# 2. Deploy to Firebase
firebase deploy --only functions

# 3. Update webhook URL in LINE Console
```

#### 4. Web Dashboard Setup
```bash
# 1. Build frontend
npm run build

# 2. Deploy to Firebase Hosting
firebase deploy --only hosting
```
